# Lab 2 — Apply RIFCC to 5 prompts

**Why this matters.** A single walked prompt is muscle. Five walked prompts back-to-back is the
muscle memory you need when a sprint dumps 12 fuzzy asks on you in one standup. Batching also
surfaces FM4 (context loss) faster than any single prompt can.

Take 5 fuzzy asks from `starter/asks.md`. Walk each through RIFCC. Save the structured prompts
in `starter/walked.md`.

## Acceptance criteria

- 5 walked prompts in `starter/walked.md`.
- ≥ 5 `walk_rifcc_run` events.
- `confidence_score` medium/high.
