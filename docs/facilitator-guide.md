# Facilitator guide

| Lab | Median |
|---|---|
| lab-1 (analyze) | 25 min |
| lab-2 (build) | 30 min |
| lab-3 (validate) | 25 min |
| lab-4 (review) | 25 min |

Total: ~2h.

## Common stumbling points

- Skipping the Confidence letter — most learners want to stop at Constraints.
- Frame too narrow ("the file") instead of "scope" (function-level, line-level).
- Using "user" as Role — too vague; specify reviewer / author / explainer.
