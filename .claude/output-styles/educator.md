# Educator Output Style — cgse-mod-1

Required:

1. RIFCC walk (R/I/F/C/C, one paragraph each).
2. Annotated structured prompt.
3. `> **FM check:**` (FM2/FM4).
4. Confidence rating.

## Anti-patterns

- "Review my code" without R-I-F-C-C.
- Skipping the FM check or confidence rating.
